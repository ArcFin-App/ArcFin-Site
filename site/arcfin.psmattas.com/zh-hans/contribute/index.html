贡献代码

欢迎提交拉取请求。先阅读 CONTRIBUTING.md 了解如何构建和项目约定，再阅读 ARCHITECTURE.md 了解 App 的结构。带有 Good First Issue 标签的 Issue 会写明从哪个文件开始，以及怎样才算“完成”。

  • 每次提交都要签名。 Arcfin 使用 Developer Certificate of Origin。用 git commit -s 提交即可添加 Signed-off-by: 行。没有 CLA，也无需转让版权；你的作品版权仍归你所有。
  • 让文本可翻译。 App 中的新文本要在同一个拉取请求中加入 String Catalogs。
  • 请遵守行为准则。

翻译 Arcfin

Arcfin 支持英语、德语、法语、西班牙语、简体中文、巴西葡萄牙语、日语、意大利语、韩语、荷兰语和俄语。最初的十种翻译由机器完成，需要母语使用者审校。

要修正翻译或添加语言，请提交 Translation 类型的 Issue。翻译指南介绍了具体做法。

AI 辅助开发

Arcfin 由一名开发者借助 AI 编程工具编写。AI 按照维护者制定的规格编写代码，不决定架构、设计或要做什么。每项改动在合并前都由维护者阅读和测试，维护者对发布的一切负责。贡献者也可以按照 CONTRIBUTING.md 中的规则使用 AI 工具。

禁止盗版

Arcfin 是一款播放器，用于播放你拥有或有权观看的媒体。项目中的任何地方都不允许讨论盗版、请求盗版内容方面的帮助或发布盗版工具和网站的链接，包括 issue、拉取请求和支持邮件，相关内容会被关闭或删除。

分支项目与 Arcfin 名称

代码可依据 AGPL-3.0 自由派生。Arcfin 的名称、标志和 App 图标不在代码许可证范围内，因此派生项目需要使用自己的名称和图标。详见 TRADEMARK.md。

更喜欢用邮件？

不适合放在 Issue 中的事情请发送至：contribution.arcfin@psmattas.com。请勿发送密码、服务器令牌或其他私人信息。安全问题请发送至 security@psmattas.com。
