服务器插件

Arcfin Sync

你的 Jellyfin 服务器的可选插件。没有它 Arcfin 也能正常使用；装上后，你的设置会在设备间跟着你走，服务器可以给你发送通知，管理员可以为所有人设置默认值和锁定，家庭可以使用观影派对和安全管理，下载也会更小。

本页内容

它带来了什么

最新的在前。从 0.6.0 版本开始的每项功能在服务器管理员开启前都保持关闭，插件更新时已在使用的功能会继续开启。没有插件 Arcfin 也能正常使用。

  • 可视化效果设置。音乐可视化效果的样式、显示位置和颜色会在你的设备之间同步，管理员也可以像其他设置一样为它们设定默认值或锁定。需要 0.7.1 及以上版本，以及 Arcfin 0.5.0（Build 5）或以上版本。
  • 来自服务器的通知。你的 Seerr 请求被批准、拒绝或可以观看时，Arcfin 会通知你，无需在该设备上登录 Seerr。如果你在 Seerr 中管理请求，还会在有请求等待批准、被自动批准或失败时通知你。如果你报告过问题或管理问题，会在问题被报告、收到评论、被解决或重新打开时收到通知。公告和提前一天的计划维护也会以通知形式送达，管理员还可以在控制台给某个人发送测试通知。你自己的操作不会通知你。这不是即时推送通知：打开的 Arcfin 会立刻收到，关闭的 Arcfin 会在下次打开或 iOS 允许其在后台检查时收到。适用于 iPhone、iPad 和 Mac；Apple TV 会在首页显示公告。0.7.0 及以后版本，需要 Arcfin 0.5.0(build 4)或更高版本。
  • 通过服务器处理 Seerr 问题。报告作品问题、跟进并回复你的问题；如果你在 Seerr 中管理问题，还可以解决、重新打开或删除，全部在 Arcfin 中完成。通过服务器使用 Seerr 时，这些操作以你的身份、按你自己的 Seerr 权限进行。0.7.0 及以后版本，需要 Arcfin 0.5.0(build 4)或更高版本。
  • 观影派对。一起看点什么，各自用自己的屏幕。在 iPhone、iPad、Mac 或 Apple TV 上从首页或作品页面发起派对：选一部电影，或选一部剧集及其季和集。宾客在其中任一设备上输入六位字符代码即可加入，在 iPhone 和 iPad 上也可以扫描二维码，绝不通过链接。你可以提前最多 30 天安排派对，作为主持人，你能看到每位宾客当地会是几点。Arcfin 会创建一个 Jellyfin SyncPlay 群组，因此使用其他支持 SyncPlay 的应用的人也能加入；主持人需要使用 Arcfin。0.6.0 及更高版本，需要 Arcfin 0.5.0（build 3）或更高版本。
  • 通过你的服务器使用 Seerr 和 TMDB。管理员把 Seerr API 密钥和 TMDB 密钥填入插件。它们使用 AES-256-GCM 加密存储，绝不会传到任何设备。每次 Seerr 调用都以使用者本人的身份进行，使用其自己的权限和请求限额，并且只访问 Arcfin 需要的 Seerr 部分。Seerr 停机期间发出的请求会在队列中等待，恢复后再发送。Seerr 可以为服务器设置一个本地地址，为应用设置一个公网地址。不使用此功能时，每台设备像以前一样自行登录 Seerr。0.6.0 及更高版本，需要 Arcfin 0.5.0（build 3）或更高版本。
  • 只有你的服务器能下达的命令。服务器有自己的签名密钥，可以按计划更换，每个新密钥都由上一个密钥签名。只有经该密钥签名的命令 Arcfin 才会执行：清除忘记的 PIN、在某人的所有设备上锁定或解锁个人资料（如果你愿意，还可以同时停用其 Jellyfin 账户），或抹掉丢失的设备，即删除其下载内容、锁定并退出登录。PIN 绝不会离开设备。0.6.0 及更高版本，需要 Arcfin 0.5.0（build 3）或更高版本。
  • 信任服务器的密钥。通过 HTTPS 时，设备会自动信任密钥。通过普通 HTTP 时，需要有人输入密钥指纹的最后四个字符来确认，或由 Arcfin 将其与服务器已保存的 HTTPS 地址核对。对于只在自家网络中使用的家庭，管理员可以选择通过 HTTP 信任密钥。0.6.0 及更高版本，需要 Arcfin 0.5.0（build 3）或更高版本。
  • PIN 规则和受信任设备。管理员可以选择谁需要 PIN（没有人、所有人或选定的人）、PIN 的最短长度（4 到 8 位数字），以及输错多少次会锁定个人资料。开启受信任设备后，新设备会显示一个代码，并等待此人受信任的某台 iPhone 或 iPad 或管理员批准。0.6.0 及更高版本，需要 Arcfin 0.5.0（build 3）或更高版本。
  • 更安全的登录。管理员可以要求在外使用 HTTPS；本地网络地址不需要。他们可以选择如何处理跟不上密钥更换的设备（退出登录，或退出登录并锁定），还可以让无法遵循这些规则的旧版 Arcfin 退出登录。0.6.0 及更高版本，需要 Arcfin 0.5.0（build 3）或更高版本。
  • 观看时长和就寝时间。为每个人分别设置工作日和周末的每日分钟数，以及就寝时间，按其所在时区计算。时间统计涵盖服务器上的所有应用。Arcfin 会提前 10 分钟和 5 分钟提醒，然后停止播放并显示消息。0.6.0 及更高版本，需要 Arcfin 0.5.0（build 3）或更高版本。
  • 下载限额。限制大家为电影和剧集保留的下载作品数量和 GB 数，以及音乐的专辑数、歌曲数和 GB 数，以先达到者为准，还可以为任何一个人单独设置限额。同一作品在某人的多台设备上只计算一次。“下载”和“已下载的音乐”会显示已用多少。0.6.0 及更高版本，需要 Arcfin 0.5.0（build 3）或更高版本。
  • 谁在观看？在几个人共用的账户上，比如客厅电视上的那个，Arcfin 会询问谁在观看，并把进度和观看状态也复制给那个人。0.6.0 及更高版本，需要 Arcfin 0.5.0（build 3）或更高版本。
  • 公告和计划维护。管理员发布的消息，以及服务器因维护而停机的时间，会显示在首页顶部。0.6.0 及更高版本，需要 Arcfin 0.5.0（build 3）或更高版本。
  • 从“继续观看”和“接下来”中隐藏。隐藏一部作品或一部剧集后，它会在你的所有设备上隐藏，并为你保存在服务器上。再次播放时它会重新出现。0.6.0 及更高版本，需要 Arcfin 0.5.0（build 3）或更高版本。
  • 推荐。首页上的“精选推荐”、“因为你看过”和“本服务器热门”行。“热门”只显示过去 30 天内至少有另外两个人播放过的作品。0.6.0 及更高版本，需要 Arcfin 0.5.0（build 3）或更高版本。
  • 进行中的会话和历史记录。管理员可以结束、锁定、移除成员或改期任何观影派对或 Pick Together 会话，并选择历史记录保留多久：若干天，或永久保留。0.6.0 及更高版本，需要 Arcfin 0.5.0（build 3）或更高版本。
  • Pick Together。不知道看什么？每个人在自己的 iPhone 或 iPad 上滑动浏览影片，直到大家都喜欢同一部，然后在一台设备上、另一台设备上，或通过 SyncPlay 一起同步观看。扫描二维码或输入代码即可加入，每个人只会看到会话中所有人都有权观看的影片。发起会话的设备担任主持：它发放新影片、移除成员并锁定会话。0.5.0 及更高版本，需要 Arcfin 0.5.0（build 3）或更高版本。
  • 设置跟着你走。在 iPhone 上改一项设置，iPad、Mac 和 Apple TV 上也会同步改好。只对某类设备有意义的设置，比如 Mac 的窗口选项或 Apple TV 的焦点选项，只留在这类设备上。
  • 设备与同步。每台设备可以选择同步方式：自动、在使用其他设备的更改前先询问你的“先询问”，或“关闭”。你还可以把一台设备的设置发送到其他所有设备。它位于 Arcfin 的“设置 › 服务器 › 设备与同步”中。
  • 所有设备一目了然。插件会记录你使用 Arcfin 的每台设备，包括名称、平台、应用版本和最后一次出现的时间。你可以重命名或移除自己的设备，管理员可以对任何人的设备这样做。
  • 为所有人设置默认值和锁定。管理员可以给任何设置一个默认值（在用户自己选择前使用），或锁定它，让所有人都使用这个值且无法更改。可以针对服务器上所有人，也可以针对某一个人，还可以只为某一个人解锁某项设置。在应用中位于“管理 › 所有人的 Arcfin”；在 Apple TV 上位于“设置 › 服务器”。
  • 完整的设置清单。插件带有和应用相同的设置目录，包括标题、默认值、选项以及显示它们的平台。它只保存清单上的设置。
  • 更小的下载。插件会测试你的服务器显卡真正能用哪些视频编码器。如果它能编码 AV1，Arcfin 会把较低画质的下载转换为 AV1，同样画面下体积约为 H.264 的一半。管理员可以在 App 的“管理 › 硬件编码器”中查看结果。
  • 转换后的下载保留所有音轨。Jellyfin 转换下载时只保留一条音轨。插件会把你选择的每条额外音轨交给 Arcfin，这样更小的下载也能保留多种语言。

安装方法

你需要是运行 12.1 或更高版本的 Jellyfin 服务器的管理员。在任何浏览器中步骤都相同。

  1. 添加插件存储库。在 Jellyfin 中打开 Dashboard › Plugins › Repositories，添加一个新的存储库。将其命名为 Arcfin，并粘贴以下 URL：
    https://git.psmattas.com/ArcFin/Arcfin-Sync/media/branch/main/manifest.json
  2. 重启 Jellyfin。在控制台中使用 Restart，或者重启服务器或其容器。Jellyfin 会在启动时读取新的存储库。
  3. 安装插件。打开 Dashboard › Plugins › Catalog，找到 Arcfin Sync，然后选择 Install。
  4. 再次重启 Jellyfin。插件会在服务器启动时加载。之后，Arcfin Sync 会在 Dashboard › Plugins › My Plugins 中显示为 Active。
  5. 进行设置。Arcfin Sync 现在在控制台中有了自己的页面（见下文）。然后打开 Arcfin，前往“设置 › 服务器”：在 Arcfin Sync 下会显示“已连接”以及插件的版本。

更新也通过同一个存储库提供。有新版本时，Jellyfin 会在 My Plugins 中提示；安装后重启即可。

设置方法

从控制台菜单或 My Plugins 中打开 Arcfin Sync。它是一个包含九个标签页的页面：

  • Overview：插件的工作方式，以及帮助和报告问题的链接。
  • Settings：Arcfin 的每项设置。可以给任何一项设置一个默认值（在用户自己选择前使用），或锁定它，让所有人都使用你的值。
  • Users & Devices：每台用 Arcfin 登录的设备。可以重命名或移除设备，并为单个用户设置专属的默认值和锁定。
  • 功能：开启或关闭每项功能，例如 Pick Together、观影派对、推荐和从“继续观看”中隐藏，并选择谁能使用 Pick Together 和观影派对。
  • Seerr & TMDB：服务器为所有人保存的密钥、Seerr 的本地和公网地址、等待发送的请求，以及通知。
  • 安全性：服务器的签名密钥及设备如何信任它、PIN 规则、受信任设备和在外使用 HTTPS。
  • 观看时长：每日分钟数和就寝时间。
  • 家庭：会询问“谁在观看？”的共享账户、公告和计划维护。
  • 下载：每个人可以保留多少下载内容。

通知在 Seerr & TMDB 标签页中设置。勾选 Notifications are on；不做其他设置时，服务器每十分钟检查一次 Seerr。若要在变更后几秒内收到通知，请在 Seerr 的 Settings › Notifications › Webhook 中添加 Webhook：

  1. 勾选 Enable Agent。
  2. Webhook URL：插件 Notifications 卡片上的 URL。如果 Seerr 通过其他地址(例如本地或 Docker 地址)访问 Jellyfin，先在卡片上填写该地址。
  3. Authorization Header：卡片上的密钥。Custom Headers 留空。
  4. JSON Payload：替换为：
    {"notification_type": "{{notification_type}}", "request_id": "{{request_id}}", "issue_id": "{{issue_id}}"}
  5. Notification Types：全部勾选。
  6. 保存后，在卡片上选择 Wait for Seerr’s Test，再在 Seerr 中按 Test。卡片会显示测试何时到达，或出了什么问题。

其他更改管理员也可以在 Arcfin 的“管理 › 所有人的 Arcfin”中进行。更改会在每台设备下次同步时生效：打开时、切换到前台时或某项设置更改时。

用户无需做任何事。Arcfin 会自动找到插件，在“设置 › 服务器”中点按“立即同步”可马上同步。要选择设备的同步方式，请打开“设置 › 服务器 › 设备与同步”。

隐私

插件运行在你自己的 Jellyfin 服务器上。同步的设置、你的设备记录、观看时长、下载限额、Seerr 和 TMDB 密钥以及你的通知只保存在那里，不会保存在其他地方；中间仍然没有任何 Arcfin 服务器。通知保留两周。密钥和 Webhook 密钥经过加密，PIN 绝不会离开你的设备。Pick Together 会话闲置六小时后结束。过往会话和观影派对的历史记录只有在管理员选择时才会保留，保留多久也由管理员决定。隐私政策说明了会保存哪些内容。

有哪些变化

插件的每个版本都列在更新日志的插件下。有新版本发布时会自动更新。

插件有问题？请在 App 的存储库中提交一个 Issue，并注明 Arcfin Sync 及其版本。
