Contribute to Arcfin

Arcfin is open source under AGPL-3.0-or-later — help shape a thoughtful native Jellyfin experience for the Apple ecosystem.

Code and issue tracker

Arcfin is hosted on a self-hosted Gitea instance, not GitHub or GitLab directly — but you can sign in there with your existing GitHub or GitLab account, no separate account needed.

View Source Arcfin Organization

Report a bug or request a feature

Use the issue tracker on the app repo. You'll need to sign in first (GitHub, GitLab, or a Gitea account all work).

  • Report a bug
  • Request a feature
  • Ask a question

Contributing code

Pull requests are welcome. Every commit needs a DCO sign-off — run git commit -s when you commit, which adds a Signed-off-by: trailer. That's it — no CLA, no copyright assignment, you keep copyright on your own contributions. See CONTRIBUTING.md for build setup and code standards.

The "Arcfin" name and logo aren't covered by the code license — see TRADEMARK.md if you're forking rather than contributing back.

Other ways to help

  • Try the TestFlight build and share clear, reproducible feedback.
  • Suggest improvements to the experience, accessibility, or platform support.
  • Share ideas for integrations with Jellyfin, Seerr, Streamystats, and related tools.
