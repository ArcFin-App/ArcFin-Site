Getting started

What do I need to use Arcfin?

A Jellyfin server of your own, or an account on one that someone you trust runs, and a device running iOS 26, iPadOS 26, macOS 26 or tvOS 26.

Arcfin doesn’t provide or host any content. Everything it plays comes from your server.

How do I install Arcfin?

Arcfin is in public beta. Install TestFlight from the App Store, then open the Arcfin invite on your iPhone, iPad, Mac or Apple TV. New builds install automatically once Apple approves them.

Arcfin goes to the App Store at version 1.0.0.

Can my family use their own profiles?

Yes. Each Jellyfin user can be a profile in Arcfin, with their own progress and recommendations. Each profile can be locked with Face ID, Touch ID or a PIN, and the server’s parental controls and access schedules apply as they do in other Jellyfin apps.

Setup

Connecting to your server

Arcfin can’t reach my server.
  • Check the address works in a browser on the same device.
  • Include the port if your server uses one, for example http://192.168.1.20:8096.
  • If your server lives under a path, such as https://example.com/jellyfin, include the path.
  • On iPhone, iPad and Mac, make sure Arcfin has Local Network access in Settings › Privacy & Security if the server is on your home network.
Should I use http:// or https://?

Use the address your server is actually set up for. If your server has HTTPS, use https://; it keeps your password and viewing private on the network. Anything reachable from outside your home should use HTTPS.

Can Arcfin switch between my home and remote address?

Yes. Add both addresses in Settings › Server and tell Arcfin which Wi-Fi network is home. It reads the current Wi-Fi name on your device to pick the right one. iOS asks for location permission to read the network name; the location itself is never used, stored or sent anywhere.

Does Arcfin work with Seerr?

Yes. Add your Seerr server in Settings › Integrations to browse, request and keep a watchlist. Each profile signs in to Seerr on its own.

Watching

Playback

A video won’t play, or stutters.

Arcfin has three playback engines. Auto (the default) uses Aether and falls back to AVFoundation or VLC if a file won’t open. Try choosing a specific engine in Settings › Playback, or lower the streaming quality so the server transcodes.

If it still fails, please report it with the file’s codec details from the player’s Media Info.

Where do subtitle styles and playback speed live?

In Settings › Playback. You can also change audio tracks, subtitles and speed from the player’s menu while watching.

Can I watch with friends?

Yes, two ways: SharePlay over FaceTime, or Jellyfin’s own SyncPlay from the player menu.

Offline

Downloads

Where can I download?

On iPhone, iPad and Mac. Apple TV has no lasting storage, so it can’t keep downloads.

Does watching offline count on my server?

Yes. Arcfin saves your progress on the device and syncs it back to your server the next time you’re online.

What are Smart Downloads?

Smart Downloads keep the next episodes of the shows you’re watching downloaded and remove the ones you’ve finished, within a storage budget you set in Settings › Downloads. Keep Downloaded on a show’s page does the same for just that show.

TestFlight

The beta

When will I get a new build?

Every public build goes through Apple’s TestFlight review first. A new version usually takes 1 to 3 days. A new build of an existing version is usually through within 24 hours, but can take as long as a new version.

Can I get builds sooner?

Internal testers get each build as soon as it’s uploaded, before Apple’s review. Seats are limited and these builds are the least tested. To ask for one, email support.arcfin@psmattas.com with the Apple Account email to invite and the devices you’d test on.

How do I report a problem well?

Use Settings › About › Report a Problem, or open an issue. Please include:

  • Your device and OS version
  • Your Jellyfin server version (Settings › Server)
  • What you did right before it happened
  • A screen recording, for anything visual

Settings › About › Share Diagnostics makes a text file of the app’s log to attach. It can include your server’s address and the titles you played, so look it over before posting it publicly.
