Server plugin

Arcfin Sync

An optional plugin for your Jellyfin server. Arcfin works fine without it; with it, your settings follow you between devices, admins can set defaults and locks for everyone, and downloads get smaller.

Latest version 0.3.0 · Free and open source under the AGPL-3.0

On this page

What it adds

  • Pick Together. Can’t decide what to watch? Everyone swipes through titles on their own iPhone or iPad until you all like the same one, then watches it on one device, on another, or together in sync with SyncPlay. People join by scanning a QR code or entering a code, and each person only gets titles everyone in the session is allowed to see. The device that starts a session hosts it: it deals new titles, removes people and locks the session. Version 0.5.0 and later, with Arcfin 0.5.0 (build 3) or later.
  • Settings that follow you. Change a setting on your iPhone and it’s there on your iPad, Mac and Apple TV. Settings that only make sense on one kind of device, like Mac window options or Apple TV focus options, stay on that kind of device.
  • Devices & Sync. Each device chooses how it syncs: automatically, Ask First to check with you before using changes from another device, or Off. You can also send one device’s settings to all your others. It’s in Arcfin under Settings › Server › Devices & Sync.
  • Your devices in one place. The plugin keeps a record of each device you use Arcfin on, with its name, platform, app version and when it was last seen. You can rename or forget your own devices, and admins can do it for anyone.
  • Defaults and locks for everyone. Admins give any setting a default, used until someone picks their own, or lock it so everyone gets that value and can’t change it. They can do it for everyone on the server or for one person, and unlock a setting for one person. In the app it’s Admin › Arcfin for Everyone; on Apple TV it’s in Settings › Server.
  • The full list of settings. The plugin carries the same catalogue of settings as the app, with their titles, defaults, choices and the platforms that show them. It only stores settings on that list.
  • Smaller downloads. The plugin tests which video encoders your server’s graphics card can really use. When it can encode AV1, Arcfin converts lower-quality downloads to AV1, which is about half the size of H.264 for the same picture. Admins can see the results in the app under Admin › Hardware Encoders.
  • Every audio track in a converted download. Jellyfin keeps only one audio track when it converts a download. The plugin hands Arcfin each extra track you pick, so a smaller download can keep several languages.

Installing it

You need to be an administrator on a Jellyfin server running version 12.1 or later. The steps are the same in any browser.

  1. Add the plugin repository. In Jellyfin, open Dashboard › Plugins › Repositories and add a new repository. Call it Arcfin, and paste this URL:
    https://git.psmattas.com/ArcFin/Arcfin-Sync/media/branch/main/manifest.json
  2. Restart Jellyfin. Use Restart on the dashboard, or restart the server or its container. Jellyfin reads the new repository when it starts.
  3. Install the plugin. Open Dashboard › Plugins › Catalog, find Arcfin Sync and choose Install.
  4. Restart Jellyfin again. Plugins load when the server starts. Afterwards, Arcfin Sync shows as Active under Dashboard › Plugins › My Plugins.
  5. Set it up. Arcfin Sync now has its own page in the dashboard (see below). Then open Arcfin and go to Settings › Server: under Arcfin Sync it shows Connected with the plugin’s version.

Updates come through the same repository. When a new version is out, Jellyfin offers it under My Plugins; install it and restart.

Setting it up

Open Arcfin Sync from the dashboard’s menu, or from My Plugins. It’s one page with four tabs:

  • Overview: how the plugin works, with links to help and to report a problem.
  • Settings: every Arcfin setting. Give any of them a default, used until someone picks their own, or lock it so everyone gets your value.
  • Users & Devices: every device signed in with Arcfin. Rename or forget one, and give a single user their own defaults and locks.
  • Pick Together: turn it on or off for everyone, or for chosen users. It’s on to begin with.

Admins can make the same changes in Arcfin, under Admin › Arcfin for Everyone. Changes reach each device the next time Arcfin syncs: when it opens, comes to the front, or a setting changes.

Users don’t need to do anything. Arcfin finds the plugin on its own, and Sync Now in Settings › Server syncs straight away. To choose how a device syncs, open Settings › Server › Devices & Sync.

Privacy

The plugin runs on your own Jellyfin server. Synced settings and the record of your devices are stored there and nowhere else; there’s still no Arcfin server in the middle. Pick Together sessions are only kept in the server’s memory while they’re in use, and end after six hours without activity. The Privacy Policy covers what’s kept.

What’s changed

Every release of the plugin is in the changelog, under Plugin. It updates on its own when a new version is published.

Something wrong with the plugin? Open an issue in the app repository and mention Arcfin Sync and its version.

Cookies This site uses only a security cookie from Cloudflare and your theme and language choices, kept in your browser. It counts visits with Cloudflare Web Analytics, which sets no cookies and doesn’t follow you around the web. No ads.
