Aportar código

Los pull requests son bienvenidos. Empieza por CONTRIBUTING.md para compilar y conocer las convenciones del proyecto, y por ARCHITECTURE.md para ver cómo encaja la app. Las incidencias con la etiqueta Good First Issue dicen en qué archivo empezar y qué significa “terminado”.

  • Firma cada commit. Arcfin usa el Developer Certificate of Origin. Haz commit con git commit -s para añadir la línea Signed-off-by:. No hay CLA ni cesión de derechos; conservas los derechos de autor de tu trabajo.
  • Haz el texto traducible. El texto nuevo de la app va a los String Catalogs en el mismo pull request.
  • Sigue el código de conducta.

Traducir Arcfin

Arcfin está disponible en inglés, alemán, francés, español, chino simplificado, portugués de Brasil, japonés, italiano, coreano, neerlandés y ruso. Las diez primeras traducciones se hicieron automáticamente y necesitan hablantes nativos que las revisen.

Para corregir una traducción o añadir un idioma, abre una incidencia de tipo Translation. La guía de traducción explica cómo.

Desarrollo asistido por IA

Arcfin lo escribe una persona con ayuda de herramientas de IA. La IA escribe código según especificaciones que define el mantenedor; no decide la arquitectura, el diseño ni qué se construye. El mantenedor lee y prueba cada cambio antes de integrarlo, y es responsable de todo lo que se publica. Los colaboradores también pueden usar herramientas de IA, según las reglas de CONTRIBUTING.md.

Forks y el nombre Arcfin

El código se puede bifurcar libremente bajo la AGPL-3.0. El nombre, el logotipo y el icono de Arcfin no están cubiertos por la licencia del código, así que un fork necesita nombre e icono propios. Consulta TRADEMARK.md.

¿Prefieres el correo?

Para todo lo que no encaje en el gestor de incidencias: contribution.arcfin@psmattas.com. No envíes contraseñas, tokens del servidor ni otros datos privados. Los problemas de seguridad van a security@psmattas.com.
