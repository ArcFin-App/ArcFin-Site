코드로 기여하기

풀 리퀘스트를 환영합니다. 빌드 방법과 프로젝트 규칙은 CONTRIBUTING.md, 앱 구조는 ARCHITECTURE.md에서 시작하세요. Good First Issue 레이블이 붙은 이슈에는 어떤 파일에서 시작할지, 무엇이 “완료”인지 적혀 있습니다.

  • 모든 커밋에 서명하세요. Arcfin은 Developer Certificate of Origin을 사용합니다. git commit -s로 커밋하면 Signed-off-by: 줄이 추가됩니다. CLA도 저작권 양도도 없으며, 작업물의 저작권은 그대로 본인에게 있습니다.
  • 텍스트는 번역할 수 있게. 앱의 새 텍스트는 같은 풀 리퀘스트에서 String Catalogs에 넣습니다.
  • 행동 강령을 지켜 주세요.

Arcfin 번역하기

Arcfin은 영어, 독일어, 프랑스어, 스페인어, 중국어 간체, 브라질 포르투갈어, 일본어, 이탈리아어, 한국어, 네덜란드어, 러시아어로 제공됩니다. 처음 10개 번역은 기계 번역이라 원어민의 검토가 필요합니다.

번역을 고치거나 언어를 추가하려면 Translation 이슈를 만드세요. 방법은 번역 안내서에 있습니다.

AI의 도움을 받는 개발

Arcfin은 한 명의 개발자가 AI 코딩 도구의 도움을 받아 작성합니다. AI는 메인테이너가 정한 사양에 따라 코드를 작성할 뿐, 아키텍처, 디자인, 무엇을 만들지는 정하지 않습니다. 모든 변경 사항은 병합 전에 메인테이너가 읽고 테스트하며, 배포되는 모든 것은 메인테이너가 책임집니다. 기여자도 CONTRIBUTING.md의 규칙에 따라 AI 도구를 쓸 수 있습니다.

포크와 Arcfin 이름

코드는 AGPL-3.0에 따라 자유롭게 포크할 수 있습니다. Arcfin의 이름, 로고, 앱 아이콘은 코드 라이선스의 적용을 받지 않으므로 포크에는 고유한 이름과 아이콘이 필요합니다. TRADEMARK.md를 참고하세요.
