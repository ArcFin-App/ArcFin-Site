Участие в коде

Pull request приветствуются. Начните с CONTRIBUTING.md, чтобы узнать, как собрать проект и какие в нём соглашения, и с ARCHITECTURE.md, чтобы понять, как устроено приложение. В issue с меткой Good First Issue указано, с какого файла начать и что значит «готово».

  • Подписывайте каждый коммит. Arcfin использует Developer Certificate of Origin. Делайте коммиты с git commit -s, чтобы добавить строку Signed-off-by:. Никакого CLA и передачи прав: авторские права на вашу работу остаются у вас.
  • Делайте текст переводимым. Новый текст приложения попадает в String Catalogs в том же pull request.
  • Соблюдайте Кодекс поведения.

Перевод Arcfin

Arcfin доступен на английском, немецком, французском, испанском, упрощённом китайском, бразильском португальском, японском, итальянском, корейском, нидерландском и русском. Первые десять переводов сделаны машинно, и их должны проверить носители языка.

Чтобы исправить перевод или добавить язык, создайте issue типа Translation. В руководстве по переводу описано, как это сделать.

Разработка с помощью ИИ

Arcfin пишет один разработчик с помощью инструментов ИИ. ИИ пишет код по спецификациям, которые задаёт мейнтейнер; он не решает, какой будет архитектура, дизайн и что создавать. Мейнтейнер читает и тестирует каждое изменение перед слиянием и отвечает за всё, что выходит. Участники тоже могут пользоваться инструментами ИИ по правилам из CONTRIBUTING.md.

Форки и имя Arcfin

Код можно свободно форкать по лицензии AGPL-3.0. Название, логотип и значок Arcfin не подпадают под лицензию кода, поэтому форку нужны своё название и значок. См. TRADEMARK.md.
