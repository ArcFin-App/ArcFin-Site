Contribuer au code

Les pull requests sont les bienvenues. Commencez par CONTRIBUTING.md pour compiler et connaître les conventions du projet, et par ARCHITECTURE.md pour comprendre l’architecture de l’app. Les tickets étiquetés Good First Issue indiquent par quel fichier commencer et ce que « terminé » veut dire.

  • Signez chaque commit. Arcfin utilise le Developer Certificate of Origin. Faites vos commits avec git commit -s pour ajouter la ligne Signed-off-by:. Pas de CLA ni de cession de droits ; vous gardez les droits d’auteur sur votre travail.
  • Rendez le texte traduisible. Tout nouveau texte de l’app va dans les String Catalogs dans la même pull request.
  • Respectez le code de conduite.

Traduire Arcfin

Arcfin est disponible en anglais, allemand, français, espagnol, chinois simplifié, portugais du Brésil, japonais, italien, coréen, néerlandais et russe. Les dix premières traductions ont été faites automatiquement et ont besoin de locuteurs natifs pour les vérifier.

Pour corriger une traduction ou ajouter une langue, ouvrez un ticket Translation. Le guide de traduction explique comment faire.

Développement assisté par IA

Arcfin est écrit par un seul développeur avec l’aide d’outils d’IA. L’IA écrit du code selon des spécifications définies par le mainteneur ; elle ne décide ni de l’architecture, ni du design, ni de ce qui est construit. Chaque changement est lu et testé par le mainteneur avant d’être intégré, et le mainteneur est responsable de tout ce qui est publié. Les contributeurs peuvent aussi utiliser des outils d’IA, selon les règles de CONTRIBUTING.md.

Forks et nom Arcfin

Le code peut être forké librement sous AGPL-3.0. Le nom, le logo et l’icône d’Arcfin ne sont pas couverts par la licence du code ; un fork a donc besoin de son propre nom et de sa propre icône. Voir TRADEMARK.md.

Vous préférez l’e-mail ?

Pour tout ce qui ne rentre pas dans le gestionnaire de tickets : contribution.arcfin@psmattas.com. N’envoyez pas de mots de passe, de jetons de serveur ni d’autres informations privées. Les problèmes de sécurité vont à security@psmattas.com.
