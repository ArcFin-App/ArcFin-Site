Quick Connect

Apple TV anmelden

Mit Arcfin auf diesem iPhone oder iPad öffnet die Kamera den Code dort und meldet das Apple TV an, sobald du bestätigst. Ohne Arcfin gib diesen Code in Jellyfin auf einem Gerät ein, auf dem du schon angemeldet bist, unter deinem Profil und dann Quick Connect.

Quick Connect auf deinem Server öffnen Arcfin holen

Der Code und die Adresse deines Servers bleiben im Link auf diesem Gerät. Dein Browser sendet sie nicht an diese Website, und nichts wird gespeichert.
