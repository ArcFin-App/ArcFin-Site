Code beitragen

Pull Requests sind willkommen. Fang mit CONTRIBUTING.md an, um zu bauen und die Konventionen des Projekts kennenzulernen, und mit ARCHITECTURE.md, um zu sehen, wie die App aufgebaut ist. Issues mit dem Label Good First Issue sagen, in welcher Datei du anfängst und wann es „fertig“ ist.

  • Zeichne jeden Commit ab. Arcfin nutzt das Developer Certificate of Origin. Committe mit git commit -s, um die Zeile Signed-off-by: hinzuzufügen. Es gibt kein CLA und keine Übertragung von Urheberrechten; das Urheberrecht an deiner Arbeit bleibt bei dir.
  • Mach Texte übersetzbar. Neuer Text in der App kommt im selben Pull Request in die String Catalogs.
  • Halte dich an den Verhaltenskodex.

Arcfin übersetzen

Arcfin gibt es auf Englisch, Deutsch, Französisch, Spanisch, vereinfachtem Chinesisch, brasilianischem Portugiesisch, Japanisch, Italienisch, Koreanisch, Niederländisch und Russisch. Die ersten zehn Übersetzungen wurden maschinell erstellt und brauchen Muttersprachler, die sie prüfen.

Um eine Übersetzung zu verbessern oder eine Sprache hinzuzufügen, erstelle ein Translation-Issue. Der Übersetzungsleitfaden erklärt, wie es geht.

KI-gestützte Entwicklung

Arcfin wird von einem Entwickler mit Hilfe von KI-Werkzeugen geschrieben. Die KI schreibt Code nach Vorgaben, die der Maintainer festlegt; sie entscheidet nicht über Architektur, Design oder was gebaut wird. Jede Änderung wird vom Maintainer gelesen und getestet, bevor sie übernommen wird, und der Maintainer ist für alles verantwortlich, was ausgeliefert wird. Mitwirkende dürfen KI-Werkzeuge ebenfalls nutzen, nach den Regeln in CONTRIBUTING.md.

Forks und der Name Arcfin

Der Code darf unter der AGPL-3.0 geforkt werden. Name, Logo und App-Symbol von Arcfin fallen nicht unter die Code-Lizenz, ein Fork braucht also einen eigenen Namen und ein eigenes Symbol. Siehe TRADEMARK.md.

Lieber per E-Mail?

Für alles, was nicht in den Issue-Tracker passt: contribution.arcfin@psmattas.com. Bitte schick keine Passwörter, Server-Tokens oder andere private Daten. Sicherheitsprobleme gehen an security@psmattas.com.
